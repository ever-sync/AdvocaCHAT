# AdvocaCHAT WhatsApp (Baileys)

Serviço persistente para pareamento, envio e recebimento do WhatsApp pelo Baileys.

Variáveis: `BAILEYS_ADMIN_TOKEN` e `BAILEYS_SESSIONS_PATH=/data/baileys`.
Monte um volume em `/data` e publique a URL terminada em `/baileys` como
`BAILEYS_BASE_URL` nas Supabase Edge Functions.
